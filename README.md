# RTS-Game
a real time strategy game built with Godot4, made with the Tiny Swords Asset pack made by pixel-frog, as i didn't want to make assets. this project is going to include resource gathering, unit movement, structure building and unit fighting. 


# what is included right now
right now all it includes is building spawning and basic unit spawning via demo keys to test.
those keys are:

- "B" for spawning buildings at the mouse pointer
- "E" for spawning units at the mouse pointer

it also includes unit movement after selection with the right mouse button allowing for the player to right click where he/she wants the units to move to.
